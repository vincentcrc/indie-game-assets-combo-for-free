# Game asset sources

Use the relevant provider below. Check the current listing and the license of the exact file or version before recommending it for release.

## Art packs, sprites, and UI

- **Kenney** covers 2D sprites, tiles, UI, VFX, low-poly 3D, textures, and game sound packs. Use the [asset catalog](https://kenney.nl/assets), category filters, and `?search=...`. Individual packs in this catalog use CC0 and can be downloaded without an account via the official Download flow and the option to continue without donating. The All-in-1 bundle is a separate product. The Kenney logo is reserved for official projects. [Kenney support and asset license](https://kenney.nl/support)
- **OpenGameArt** covers 2D and 3D art, concept art, tiles, textures, music, and sound effects. Use [advanced search](https://opengameart.org/art-search-advanced) and filter by type and license. If the web index has limited coverage, use the public page or a domain-scoped search. On the listing, use **File(s)** for the actual downloads. Follow the author's credit instructions and choose an applicable offered license for the exact file. CC0, CC BY, OGA BY, CC BY-SA, GPL, and other listing-specific terms have different credit, distribution, and DRM implications. [OpenGameArt FAQ](https://opengameart.org/content/faq)
- **itch.io** covers sprites, tiles, UI, fonts, animation, 3D, SFX, and music. Start with [free game assets](https://itch.io/game-assets/free) and narrow by tag. [Global keyword search](https://itch.io/search) also includes paid assets and non-asset listings. Creator terms in the description or archive control asset use. In a pay-what-you-want listing, check for a zero-price download and verify the specific file since paid add-ons and versions with different licenses can share one page. Use the page's download or account claim flow. Browse RSS can help with discovery, and the server API covers account-specific resources. [Creator pricing](https://itch.io/docs/creators/pricing) · [API and RSS](https://itch.io/docs/api/overview)

## Engine packages and marketplaces

- **Unity Asset Store** covers Unity packages, systems, templates, tools, materials, models, audio, UI, and VFX. Give the user the [Top Free storefront](https://assetstore.unity.com/top-assets/top-free) or the Unity editor's Asset Store search. Store terms §3.3 restrict automated access. For automated discovery use independent publisher sites or source repositories and verify their own licenses and download paths. Unity ID is needed to claim through **Add to My Assets** and import via **Package Manager → My Assets**. Check item EULA, editor version, render pipeline, dependencies, and Extension Asset seats. The standard EULA generally supports commercial embedded use, with restrictions on distribution of raw assets. Restricted and non-standard listings can differ. [Store terms and EULA](https://unity.com/legal/as-terms) · [Official acquisition flow](https://docs.unity.com/en-us/asset-store/downloads/purchase-asset-packages)
- **Fab** covers 3D models, environments, materials, animation, audio/VFX, and engine tools or plugins. Use [Fab Free search](https://www.fab.com/search?is_free=1) and filter by format or engine. Check the selected license and actual downloadable format. Fab Standard covers commercial incorporation in compatible tools and restricts standalone redistribution. CC BY requires credit. Some older listings carry legacy marketplace terms, and Reference Only grants a reference without source files. Eligible free files may have an official anonymous download after EULA acceptance. Account library claims and UE/UEFN workflows can require an Epic account or the official integration. [Fab EULA](https://www.fab.com/eula) · [Download and library guide](https://dev.epicgames.com/documentation/fab/purchasing-and-downloading-assets-in-fab)
- **Godot** covers addons (including editor plugins), tools, scripts, demos, templates, and some art or audio. Search the [current Godot Asset Store](https://store.godotengine.org/search/) and the [legacy Asset Library](https://godotengine.org/asset-library/asset). Items were not migrated automatically. The newer Store is available on the web and in newer Godot editors. Standalone templates can be used from the Project Manager. The CLI uses the current editor's public search endpoint and keeps zero-price matches from the first page. Use `--legacy` for the original library, where `cost` is the license. Check the specific release and engine version, read the license, and inspect the source and dependencies of an addon before enabling it. [Current Store docs](https://docs.godotengine.org/en/stable/community/asset_store/what_is_asset_store.html) · [Current editor client](https://github.com/godotengine/godot/blob/4.7-stable/editor/asset_library/asset_library_editor_plugin.cpp#L1477-L1513) · [Legacy REST API](https://github.com/godotengine/godot-asset-library/blob/master/API.md)

## 3D materials, HDRIs, and animation

- **Poly Haven** covers CC0 3D models, PBR surfaces, and HDRIs. Prefer its keyless public API for automation. The CLI identifies itself with a unique User-Agent and labels the results as Poly Haven. Use the listing or `poly-files` to get exact files, sizes, hashes, and dependencies. Select resolution, EXR/HDR or renderer-compatible formats, and the maps your pipeline needs. CC0 assets carry no attribution obligation. The live API requires source credit when showing its content and has terms separate from its assets. [API usage and terms](https://polyhaven.com/our-api) · [Agent API guide](https://polyhaven.com/llms.txt) · [Asset license](https://polyhaven.com/license)
- **Mixamo** covers humanoid characters, auto-rigging of bipeds, and motion capture. Use the [Mixamo web app](https://www.mixamo.com/) with an eligible personal Adobe ID. Supported accounts and regions are listed in the Adobe FAQ. Use the browser export options and check skeleton, in-place motion, frame rate, retargeting, and whether skin is included. Adobe allows use in finished commercial games. Keep source characters and motions out of public raw-asset redistribution unless separately authorized. [Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) · [Adobe rigging and animation workflow](https://helpx.adobe.com/creative-cloud/help/mixamo-rigging-animation.html)

## Audio and stock media

- **Freesound** covers SFX, ambience, Foley, and recorded samples. Use [public keyword search](https://freesound.org/search/) and check the individual license. CC0 and CC BY are useful for commercial releases. CC BY-NC is for noncommercial uses. Older items may use Sampling+ and need a separate license check. Originals require sign-in. The optional API requires a token for search and OAuth2 for originals. Its commercial-use terms are separate from the sound licenses and require a commercial arrangement. [FAQ](https://freesound.org/help/faq/) · [API endpoints](https://freesound.org/docs/api/resources_apiv2.html) · [API terms](https://freesound.org/docs/api/terms_of_use.html)
- **Pixabay** covers [sound effects](https://pixabay.com/sound-effects/), [music](https://pixabay.com/music/), photos, illustrations, vectors, and videos. Use the website for audio. The official keyed API covers images and video, with caching and retrieval conditions. Standard Content License terms generally permit incorporation in commercial projects without mandatory attribution. Check restrictions for standalone redistribution, identifiable people, brands, and trademark uses. Select actual Pixabay content and check the item's license. For music marked with Content ID, retain the download certificate when available. [License summary](https://pixabay.com/service/license-summary/) · [Full terms](https://pixabay.com/service/terms/) · [FAQ](https://pixabay.com/service/faq/) · [API docs](https://pixabay.com/api/docs/)

## CLI examples

```sh
python3 scripts/find_assets.py route 2d "pixel grass tiles"
python3 scripts/find_assets.py route sfx "ui click" --source freesound
python3 scripts/find_assets.py route plugins "dialogue system" --source godot
python3 scripts/find_assets.py poly-search materials "weathered brick" --limit 3
python3 scripts/find_assets.py poly-files patterned_brick_wall_03
python3 scripts/find_assets.py godot-search "inventory" --version 4.7 --kind addon --limit 3
python3 scripts/find_assets.py godot-search "platformer" --version 4.4 --legacy --limit 3
```
